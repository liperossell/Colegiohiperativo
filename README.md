📠 ## Como executar

### Plug and play (recomendado)

```powershell
git clone https://github.com/JorgeRamalho/Colegiohiperativo.git
cd Colegiohiperativo
npm run api:install   # clona infra automaticamente e instala dependências
npm run infra:up      # postgres + email-service (Docker)
.\scripts\run-dev.ps1 # API + frontend
```

Dependência de infra: [github.com/JorgeRamalho/infra](https://github.com/JorgeRamalho/infra) (clonada em `../infra` automaticamente).
